# Курсова робота: Дослідження ринку нерухомості

**Студент:** Іванов Артур Радославович студент групи 403-ТН
**Дисципліна:** Мови програмування для аналізу даних
**Тема:** Дослідження ринку нерухомості

Мета проєкту
Розвідувальний аналіз даних (EDA) ринку нерухомості на основі відкритого датасету з Kaggle (2000 записів). Виявлення прихованих закономірностей ціноутворення, побудова графіків та створення інтерактивного дашборду.

Джерело даних
[House Price Prediction Dataset (Kaggle)](https://www.kaggle.com/datasets/zafarali27/house-price-prediction-dataset)

Використані технології
- **Python** (Pandas, NumPy)
- **Matplotlib, Seaborn** (візуалізація)
- **Google Colab** (середовище розробки)
- **Tableau Public** (інтерактивний дашборд)

Структура проєкту
- `Untitled.ipynb` — основний Jupyter Notebook з кодом та аналізом.
- `house_prices_raw.csv` — вихідні дані.
- `house_prices_clean.csv` — очищені та підготовлені дані.
- `01_price_hist.png` ... `06_condition_price.png` — згенеровані графіки.

Інтерактивний дашборд
https://public.tableau.com/authoring/RealEstateMarketAnalysisMPADIvanovArtur/sheet3#1


Основні висновки
1. Найвища медіанна ціна зафіксована в локації Suburban (589 618 USD).
2. Всупереч очікуванням, площа об'єкта майже не корелює з його ціною (r=0.0015).
3. Питома ціна за квадратний фут є більш значущим показником (r=0.525).
